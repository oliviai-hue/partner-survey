# 파트너 설문 화면

이 폴더의 정적 파일만 GitHub Pages에 올릴 수 있습니다. 계정 목록, 전용 링크 목록, 응답 데이터, 인증 파일은 포함하지 않습니다.

현재 Google 설문 서버 배포 전이므로 화면은 **미리보기**로 동작합니다. 실제 수집은 Google Apps Script 웹 앱 배포와 `SURVEY_WEB_APP_URL` 연결 후 활성화됩니다.

계정별 전용 링크는 `설문 참여계정` 표에서 관리합니다. GitHub 진입 링크를 사용하면 Google 설문 웹 앱으로 이동합니다. 저장 성공 후에만 접수증과 복권을 표시합니다.

전체 작업 폴더를 업로드하지 마세요. 대상 계정 자료가 들어 있습니다.
